# Player character

Low-poly player model built from the model sheet, plus a Metal 4 iOS demo.

- `player.blend`: model, rig and clips. Legs use IK (`ctrl_foot.*`, `ctrl_pole.*`), everything else is FK.
- `export/player.glb`: game asset. 2,919 tris for the default outfit, about 4,000 for the bob, dress and Mary Janes look, 21 joints, clips `Idle`, `Idle_Look`, `Idle_Wave`, `Walk`.
- `textures/`: generated by `tools/make_textures.py`. `T_Face.png` is a 2x2 expression atlas.
- `ios/`: run `PlayerDemo.xcodeproj` on an iPhone. `project.yml` regenerates it with `xcodegen`.

## Rebuild

    python3 tools/make_textures.py
    /Applications/Blender.app/Contents/MacOS/Blender -b --factory-startup -P tools/build_all.py
    cp export/player.glb ios/PlayerDemo/Resources/

The character is 1 m tall, faces -Y in Blender and +Z in the app. All dimensions in
`tools/build_character.py` are millimetres taken from the sheet.

## Customisation

Every item is worn on one skeleton, chosen by `Outfit` in `ios/PlayerDemo/Sources/Wardrobe.swift`.

| Slot | Options | Kind |
|---|---|---|
| Hair | Short, Bunches, Bob | mesh: `SK_Hair`, `SK_Hair_Bunches`, `SK_Hair_Bob` (the bob includes the flower clip) |
| Top | Argyle, Daisy | texture on `SK_Top`: `T_Top.png`, `T_Top_Daisy.png` |
| Bottom | Shorts, Skirt, Dress | mesh: `SK_Bottoms`, `SK_Skirt`, or `SK_Dress` + `SK_Tights` |
| Shoes | Loafers, Mary Janes | mesh: `SK_Shoes`, `SK_Shoes_MaryJane` |
| Shoe colour | Brown, Terracotta, Olive, Mustard, Blue | texture: `T_Shoes*.png`, works on both shoe styles |

The dress is a whole outfit: it replaces the top and shorts, and swaps socks for tights. `SK_Body` is always worn.

To add a texture option (top or shoes): add it to `make_textures.py` (`make_top` or `shoes`), copy the PNG into
`ios/PlayerDemo/Resources/`, and add a case to the enum. It reuses the mesh's UVs.

To add a mesh option: add a builder in `build_character.py`, weight it to the existing bones, add it to `ALT_ITEMS`
and to `ALT` in `export_glb.py`, then add a case to the enum. The wave raises the hand forward, so hair may
hang to the jaw at the sides, but keep it clear of a hand at roughly (-228, -110, 566) mm.
Open shells need explicit orientation (`P.outward`): Blender renders both sides, the app culls back faces, so check hair in the app.

Alternate meshes are hidden in `player.blend`. Show them from the outliner to edit them.
Expressions are a UV offset on the `M_Face` primitive, so the face has no geometry.

## Metal notes

- The Simulator SDK has no Metal 4 API. `SimulatorRenderer.swift` is a preview using the same shaders and is
  compiled out of device builds. `Metal4Renderer.swift` is the real renderer.
- To test Metal 4 without a phone, build the Mac Catalyst destination and run with
  `MTL_DEBUG_LAYER=1 METAL_DEVICE_WRAPPER_TYPE=1`.
- Memoryless textures must stay out of residency sets.
- Debug builds accept `DEMO_OUTFIT=girl`, `DEMO_MOVE=Walk` and `DEMO_YAW=3.14` to start in a given state.
- Walk is in place. Move the world at `walkSpeed` (0.31 m/s) to keep the planted foot locked.
- Blender 5.2.2 crashed when the glTF export ran inside `temp_override`, so `export_glb.py` uses a plain call.
